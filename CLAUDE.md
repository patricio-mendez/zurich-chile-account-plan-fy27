### Updating the Site
To update the published Account Plan:

1. Edit the source HTML file: `Zurich Chile - Strategic Account Plan FY27.html`
2. Copy to the gh-pages branch as index.html
3. Push to GitHub:
   ```bash
   git checkout gh-pages
   cp "Zurich Chile - Strategic Account Plan FY27.html" index.html
   git add index.html
   git commit -m "Update Account Plan"
   git push personal gh-pages
   ```
